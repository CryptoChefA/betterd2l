Install in about a minute

BetterD2L isn't on the Chrome Web Store yet, so it loads in developer mode. That's the same extension, just installed by hand.

Download & unzip

Grab betterd2l.zip and double-click it to unzip.

Open extensions

Go to chrome://extensions and switch on Developer mode (top right).

Load it

Click Load unpacked, pick the betterd2l folder, then open D2L. Done 🌙

Questions

Is it safe? Why does Chrome say "developer mode"?

Developer mode just means the extension was loaded from a folder instead of the Chrome Web Store. The code is all public on GitHub, so you (or a CS friend) can read every line. It only runs on Langara's D2L and never sends data anywhere.

Does it work on Mac, Windows and Chromebook?

Yes. It works anywhere Chrome runs, plus Edge, Brave, Arc and Opera. Safari and Firefox aren't supported yet.

Can it break D2L or my submissions?

No. It only changes how pages look and reads your course dates. It never submits, posts or edits anything. If a page ever looks off, press Alt+Shift+D to turn it off instantly.

Something still looks bright. What do I do?

Switch to Invert mode in the popup for now, and open an issue saying which page it was. Please leave out personal info.

How do I update?

Download the new zip, replace your betterd2l folder's contents, then hit ↻ on BetterD2L in chrome://extensions. Your settings stay put. See the changelog for what's new.

Is this made by Langara or D2L?

No. It's an independent student project, not affiliated with Langara College or D2L Corporation.
